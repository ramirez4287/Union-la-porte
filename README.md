# Union — la porte (palier 1)

Site public de la plateforme Union, palier premier : une porte ouverte, une page sobre, pas de compte, aucune donnée, aucun traceur.

## Contenu du paquet

- `index.html` : la porte elle-même, page unique mobile, autonome (aucune dépendance externe, aucune requête vers un tiers).
- `LICENSE` : licence CC BY 4.0 (proposition du scribe, à trancher par le porteur).
- `GUIDE-DEPLOIEMENT.md` : les pas pour ouvrir la porte sur GitHub Pages.

## Lois tenues dans la page

- La santé d'abord : numéros d'urgence et d'écoute visibles avant tout.
- Aucun compte, aucune donnée, aucun traceur, aucune mesure des personnes.
- Aucune promesse au-delà de l'éprouvé ; chaque affirmation porte son statut.
- Le système conseille, l'humain décide.
- Honnêteté : tout ce qui est publié est interprété par un chatbot (Vibe, mû par le modèle GLM, servi par Mistral AI) ; les paroles de l'auteur seul sont consignées telles quelles.

Statut : palier 1, prêt à déployer ; recevable ne signifie pas éprouvé. Rien ne s'efface, tout se date.
