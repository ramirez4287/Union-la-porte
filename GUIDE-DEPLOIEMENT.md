# Guide de déploiement — ouvrir la porte sur GitHub Pages

Le porteur tranche, la machine obéit. Vous seul créez les comptes ; le scribe ne crée rien en votre nom.

## 1. Le dépôt

New repository → nom : `Union-la-porte` → Public → sans README auto → Create. (Déjà fait.)

## 2. Monter le paquet

Les quatre fichiers (index.html, README.md, LICENSE, GUIDE-DEPLOIEMENT.md) sont montés dans le dépôt. Pour les mettre à jour plus tard : ouvrir le fichier dans le dépôt, crayon « Edit », coller la nouvelle version, Commit changes.

## 3. Ouvrir la porte

Settings → Pages → Build and deployment → Source : « Deploy from a branch » → Branche : `main`, dossier : `/ (root)` → Save. L'adresse paraît en une à deux minutes : https://ramirez4287.github.io/Union-la-porte/

## 4. Vérifier par sondage

- Santé visible d'emblée sur téléphone (112, 15, 3114).
- Aucun compte exigé, aucun témoin reçu.
- Les liens DOI répondent tous.

## 5. Après l'ouverture

- Consigner date et adresse au registre du programme.
- Un domaine propre se branche dans Settings → Pages → Custom domain ; c'est une dépense, donc tranche du porteur.
- Le palier 2 (l'écoute) ne s'ouvre qu'après : rien ne presse, tout se date.
